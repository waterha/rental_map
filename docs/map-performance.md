# 全国地图交互性能优化

## 原因与处理

原来的相机位置、缩放和悬停状态更新都会重新渲染地图。D3 投影本身已经缓存，但投影后的 SVG 路径没有缓存：每个区域的同一条边界每次重新生成四遍，全国页的南海附图还会额外生成一遍。全国主图四层路径共约 161 万字符，浙江约 32 万、杭州约 29 万，因此相同问题在全国层级最明显。

第一轮优化将主图路径按数据和投影缓存，四个绘制层复用同一个字符串；南海附图单独缓存。只有边界数据、地区或窗口尺寸改变时才重新计算，拖动、缩放和悬停不重新生成边界。该轮保留原有视觉样式。关闭发光的对照试验没有显示明显的进一步收益，因此没有关闭发光。

鼠标输入还通过一次性的 `requestAnimationFrame` 合并为每帧最多一次相机更新。最新视图保存在引用中，滚轮的每次增量都参与累积；拖动开始读取最新值，避免读到上一帧的位置。跨地区、调整窗口和卸载时取消待执行帧，防止旧相机更新覆盖新地区的初始位置。没有持续运行的动画循环。

## 实测

2026-11-14，本机 Edge 无界面模式，1512×1080，生产构建，CPU 降速 4 倍。每项重载页面并预热后，回放 60 次真实鼠标输入；地区数据相同。此设置用于放大计算瓶颈，数值不代表所有电脑的实际帧率。

| 全国操作 | 修改前累计脚本耗时 | 修改后累计脚本耗时 | 修改前 P95 帧间隔 | 修改后 P95 帧间隔 |
| --- | ---: | ---: | ---: | ---: |
| 悬停 | 1446 ms | 39 ms | 21 ms | 17 ms |
| 拖动 | 28984 ms | 178 ms | 504 ms | 25 ms |
| 缩放 | 27948 ms | 184 ms | 521 ms | 29 ms |

拖动、缩放的累计脚本耗时均下降约 99%；不是宣称整体帧率提高 100 倍。SVG 绘制仍需要浏览器工作，显卡、屏幕尺寸和缩放倍率仍会影响体验。省市交互的脚本耗时也随缓存显著下降。

## 复测

启动生产构建服务后，执行（地址按本地服务调整）：

```powershell
npm run build
$env:TEST_BASE_URL='http://127.0.0.1:8082'
npm run benchmark:map
```

脚本依次回放全国、浙江、杭州的悬停、拖动与缩放，记录脚本耗时、主线程任务耗时、帧间隔和路径规模，报告写入忽略目录 `.local/map-benchmark.json`。不采集网络请求内容、邮箱、凭据或区县 SDK 数据。

全国连续拖动、缩放的预算为每 60 次输入累计脚本耗时不超过 1200 ms（4 倍 CPU 降速）。原始报告对此检查失败，优化后的报告通过。也可以对已有报告执行 `node scripts/benchmark-map.mjs --check-report .local/map-benchmark.json`。预算用于发现重复投影回归，不代表稳定帧率承诺；性能复测时应关闭其他高负载任务。

生产构建、性能预算、14 项浏览器测试通过，覆盖逐级进入、真实高德区县、光点详情、拖动不误入、滚轮中心、连续滚轮不丢增量、视图重置、移动端、失败恢复和账号系统。

## 第二轮：轻量全国轮廓与共享省界

全国默认视图改用预生成的 TopoJSON，而省、市和高德区县继续使用原有详细数据。原始全国 GeoJSON 保留在 `data/maps/100000.json`，前端全国页不再请求它。执行 `npm run maps:build` 可以重新生成两档全国地图，生成工具仅在开发时使用。产物通过 Vite 独立资源发布，文件名带内容哈希。

TopoJSON 把相邻省份共用的边界存成同一条弧。生成时在共享弧上运行 Douglas–Peucker 简化，而不是分别简化每个省份，因此两侧保持同一条省界。每条弧的端点保留，封闭环不足三角形时回退原始弧，多弧组成的环如果坍缩或翻转也回退。只做坐标量化和减少顶点，不删除岛屿、多边形或孔洞。默认轮廓顶点偏移上限为 0.03 度，加上小于 0.0001 度的量化误差；在 1512×1080 全国初始视图中大致为一个像素以内。相机放大到 3 倍后按需加载 0.003 度误差档，下载失败时继续使用默认轮廓。进入省市不使用全国简化数据。

全国主图每省保留一个填色与点击路径，所有省界由一份共享线网绘制，并由同一线网提供发光。不再重复叠加每省的阴影、颗粒和双侧省界描边，黑蓝色调、荧光边界和标签保留。

| 全国默认视图规模 | 第二轮前 | 第二轮后 |
| --- | ---: | ---: |
| 地图文件未压缩大小 | 582521 字节 | 103065 字节（减少约 82%） |
| 拓扑共享弧顶点数 | 16710 | 6983（减少约 58%） |
| 主图 SVG 路径数量 | 140 | 37 |
| 主图路径字符总数 | 1612488 | 364984（减少约 77%） |

相同的浏览器、视口、4 倍 CPU 降速及每项 60 次输入下，本轮实测全国拖动 P95 帧间隔从 42 ms 降到 17 ms，缩放从 50 ms 降到 21 ms。帧时序受机器负载影响，应以路径规模的确定性下降和多次实际操作共同评估，不把单次结果当作所有设备的帧率承诺。

新增 `npm run test:maps`：验证 34 个省级区域、属性、每个岛屿与孔洞的环数量、闭合与方向、共享弧端点和最大位移，以及默认数据的体积和顶点预算。2 项几何测试和 16 项浏览器测试通过；浏览器还验证详情按需加载、缩小时回退轻量数据、详情网络失败时仍可进入省份。
