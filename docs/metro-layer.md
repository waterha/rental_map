# 区县地铁图层

进入区县地图后，左上角账号按钮下方显示地铁图标。默认关闭，点击后在高德街道底图上加载线路与站点，再次点击关闭。全国、省、市不显示开关，直辖市也需进入下辖区县才能使用。返回市级或切换区县后恢复关闭。

使用高德原生 Polyline 和 Marker 叠加，缩放、拖动跟随底图。线路保留来源颜色，站点名称在高德缩放级别 14 及以上显示。房源光点位于地铁覆盖物上方。线路连线按当前区县多边形边界裁剪，保留穿越区县但两端站点都在区外的片段，排除孔洞；区外站点不绘制。原有紧凑图例显示来源城市的线路列表。

## 数据来源与含义

使用高德公开地铁数据，不调用私有 API Key，不读取本地邮箱和地图密钥。城市目录来自 `https://webapi.amap.com/subway/data/citylist.json`，杭州来源为 `https://webapi.amap.com/subway/data/3301_drw_hangzhou.json`。

来源的 `c`、`p`、`rs` 是独立示意图的画布坐标，不能投影到行政区地图。本功能使用站点 `sl` 的经纬度，依来源站点顺序连线，环线按来源标记闭合。因此显示的是**真实站点位置的连线示意**，不代表隧道逐段走向。界面明确标注“高德地铁 · 站点连线示意”和数据获取日期。仅绘制来源 `su=1` 的线路，不提供实时运营、首末班或新线开通状态。源数据可能包含跨城市互通线路，如杭州数据中的绍兴线路。

项目随附城市目录及杭州 16 条线路的快照，其他目录内城市首次开启时由 Go 服务获取。目录未收录的城市返回空线路并明确提示；上游失败时提供重试。更新目录及杭州快照：

```powershell
npm run metro:download
# 可以指定目录内其他城市，一并生成快照，例如北京：
npm run metro:download -- 110000 330100
```

公开可访问的数据仍应按来源的适用授权使用；本功能没有引入第三方运营保证。

## 缓存与实现

Go 接口为 `GET /api/metro/{districtCode}`，仅接受已知区县，后端根据其上级地区解析所属城市（含直辖市），复用该城市的线路缓存。全国、省、市请求返回 422，无效代码返回 400，未知地区返回 404。接口从随附目录映射到固定高德地址，用户不能指定上游 URL。

同城并发请求合并；成功数据缓存在内存和忽略的 `data/runtime/metro/`，快照与缓存有效期 24 小时。过期时尝试更新，上游失败时使用最近快照并标记离线缓存，5 分钟后允许重试。无法获得数据时返回 502，不绘制虚构线路。校验颜色、线路、站点数量和坐标，拒绝损坏或非有限坐标。

前端仅开启图层时请求，关闭和切换地区时取消待完成请求，防止旧区县结果覆盖新页面。会话缓存减少重复切换请求。覆盖物只在数据、地图或开关变化时创建与清理，拖动和缩放交给高德渲染。城市层级原有 SVG 地铁绘制已移除。

Docker 与隔离浏览器测试均包含 `data/metro/`。32 项 Go 测试和 19 项浏览器测试通过，新增覆盖区县层级限制、坐标转换、同城并发合并、磁盘缓存、离线回退、异常上游、杭州真实快照、图层开关、高德缩放拖动、左上角位置与账号按钮不重叠、移动端、空数据及失败重试。`npm run test:metro` 的 2 项几何测试额外验证区县裁剪、孔洞和离岛片段。与账号测试一样，隔离测试禁用真实邮件发送。
