# 市级地铁图层

进入市级地图后，左下角显示地铁图标。默认关闭，点击后加载线路与站点，再次点击关闭。全国、省级和区县不显示开关；北京、天津、上海、重庆及港澳的直接辖区页面按城市处理。切换地区后恢复关闭，不影响点击区县、房源请求和原有导航。

线路使用来源颜色高亮，随地图缩放、拖动。放大到 1.8 倍后显示站点，2.5 倍后显示站名，避免城市全景或手机视图被密集圆点覆盖。换乘站使用较大的圆点。只有开启时显示紧凑的线路图例；触屏页面保留相同操作。

## 数据来源与含义

使用高德公开地铁数据，不调用私有 API Key，不读取本地邮箱和地图密钥。城市目录来自 `https://webapi.amap.com/subway/data/citylist.json`，杭州来源为 `https://webapi.amap.com/subway/data/3301_drw_hangzhou.json`。

来源的 `c`、`p`、`rs` 是独立示意图的画布坐标，不能投影到行政区地图。本功能使用站点 `sl` 的经纬度，依来源站点顺序连线，环线按来源标记闭合。因此显示的是**真实站点位置的连线示意**，不代表隧道逐段走向。界面明确标注“高德地铁 · 站点连线示意”和数据获取日期。仅绘制来源 `su=1` 的线路，不提供实时运营、首末班或新线开通状态。源数据可能包含跨城市互通线路，如杭州数据中的绍兴线路。

项目随附城市目录及杭州 16 条线路的快照，其他目录内城市首次开启时由 Go 服务获取。目录未收录的城市返回空线路并明确提示；上游失败时提供重试。更新目录及杭州快照：

```powershell
npm run metro:download
# 可以指定目录内其他城市，一并生成快照，例如北京：
npm run metro:download -- 110000 330100
```

公开可访问的数据仍应按来源的适用授权使用；本功能没有引入第三方运营保证。

## 缓存与实现

Go 接口为 `GET /api/metro/{cityCode}`，仅接受已知城市或直接辖区页面。省级、全国及区县请求返回 422，无效代码返回 400，未知地区返回 404。接口从随附目录映射到固定高德地址，用户不能指定上游 URL。

同城并发请求合并；成功数据缓存在内存和忽略的 `data/runtime/metro/`，快照与缓存有效期 24 小时。过期时尝试更新，上游失败时使用最近快照并标记离线缓存，5 分钟后允许重试。无法获得数据时返回 502，不绘制虚构线路。校验颜色、线路、站点数量和坐标，拒绝损坏或非有限坐标。

前端仅开启图层时请求，关闭和切换地区时取消待完成请求，防止旧城市结果覆盖新城市。会话缓存减少重复切换请求。线路投影与站点投影按数据和地图投影缓存，拖动只改变相机变换，缩放不重新生成线路路径。图层禁用指针捕获，保留地图下钻和拖动。

Docker 与隔离浏览器测试均包含 `data/metro/`。32 项 Go 测试和 19 项浏览器测试通过，新增覆盖城市层级限制、坐标转换、同城并发合并、磁盘缓存、离线回退、异常上游、杭州真实快照、图层开关、缩放拖动、移动端、空数据及失败重试。与账号测试一样，隔离测试禁用真实邮件发送。
