# 合区找房

在区县街道地图中点击左上角“合区找房”图标，会回到所属市级行政地图，并默认选中刚才的区县。可以点击地图区块或面板中的区县名称来选择、取消选择。选中区域以荧光蓝高亮；选择至少两个区县后点击“一起看房”。

确认后，在一张高德街道地图中最大化展示所有所选区县，保留各区轮廓，显示这些区县的房源光点。其他区县的地图区域继续被遮罩。房源详情、出租类型切换和地铁图层沿用现有功能；地铁线路按所选区县的共同范围裁切。

按一次 ESC 会退出选区或合区浏览，返回所属市级地图。关闭面板按钮也可退出；手机无需键盘。账号等模态窗口打开时，ESC 优先处理该窗口。通过地区搜索或路径导航前往其他地区也会结束合区。

合区只改变浏览范围，不修改行政区数据和房源归属。只支持同一个市级父节点下的区县，直辖市下辖区县也可合区；允许一次选择 2–16 个区县，不强制相邻。可通过“重新选区”调整范围。发布房源时先退出合区，回到一个具体区县，避免把房源归属到多个区。

合区地址使用 `?region=330100&districts=330106,330110` 这类形式，可刷新、分享或用浏览器前进后退恢复。当前来源没有边界的区县不能选中；若历史链接的边界缺失，会提示重新选择，不显示没有遮罩的地图。

## 实现和调用量

- 市级选区复用原有行政边界，选中、取消时不调用高德。
- 合区边界把原有 Polygon/MultiPolygon 组合为一份 MultiPolygon，保留岛屿和内环。遮罩、自动适配视野、地铁裁切使用同一份几何数据，不调用高德行政区查询。
- 确认后创建一张高德地图。房源详情和租房类型切换不会重新创建底图。重新选区再确认会进入一次新的地图视图；普通底图与缩放仍会产生正常的高德请求。
- 房源只请求一次本项目的 `/api/listings?districts=330106,330110`，后端通过绑定参数执行 `district_code IN (...)`，统一筛选、统计和返回光点，避免每个区县各拉一次数据后拼接。
- 后端拒绝跨城市、非区县、重复代码、无效代码、重复参数，以及超过 16 个区县的请求。原有分页、最多 150 个光点及限流仍然生效；列表不会批量返回联系方式或账号归属。

索引与行政边界均受当前数据来源覆盖范围限制，合区不会补造缺失的边界，也不会改变房源真实位置。
